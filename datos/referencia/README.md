# Referencia

- `top3_por_eleccion.csv`: los tres primeros por instancia, Santa Fe y país, con la
  etiqueta tal cual la fuente. Se regenera con `scripts/construir_top3.py`.
- `formulas_presidenciales_1983_2023.csv`: fórmula (presidente y vice) de cada
  etiqueta en las generales 1983-2023, según el registro de candidaturas de la DINE.
  Se regenera con `scripts/ordenar_candidaturas.py`.
